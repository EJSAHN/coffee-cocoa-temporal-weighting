# Version 2 integration

- One numerical workflow now runs the empirical models, frozen event contrasts, original benchmark, portable exact-weight diagnostics and 100-design expansion.
- The original empirical estimators, climate/event definitions, outcome transformations, weights and benchmark generators are unchanged.
- Independent-design summaries retain the 100 planned designs and 40 response replicates per condition. Monte Carlo errors use the outer designs.
- Completed empirical calculations and individual simulation designs can be resumed after verification. Input, implementation or numerical-runtime changes require a new output directory.
- Supplementary Data S1 includes the original result families, the independent-design tables, exact-weight diagnostics, protocol metadata and aggregate workbook. Tables 1–3 and eight numerical plot-data tables are generated from current results.
- The local distribution renders four main figures and four supplementary figures. The public numerical distribution requires no plotting dependencies.
- Each local run produces a compact review archive, including separate comparisons against the recorded original results and independent-design aggregates.
